ZPocket 用户手册

面向日常手机端使用，涵盖配对连接、通知栏快捷审批、机型后台保活、工作区取文件、工作流控制与隐私安全。

一、安装与首次配对

  • 手机端要求：Android 7.0 及以上（主流手机选 arm64-v8a，旧款 32 位选 armeabi-v7a）。
  • 桌面端要求：电脑端已安装并登录 ZCode 桌面端（上下文下钻、子代理逐条停止、冷会话秒开需 3.18+；后台 Bash 失败摘要需 3.19+）。
  • 连接方式：打开 ZPocket 后使用与桌面端相同的账号登录，或直接扫码配对。若绑定了多台电脑，每台电脑的数据与凭据在 App 内独立隔离，可随时显式切换。

二、日常使用核心功能

  • 任务主页与双栏视图：任务按时间与项目分组展示，支持项目排序、置顶与归档。平板或折叠屏展开态（逻辑宽度 ≥600dp）自动开启「左栏任务 + 右栏会话」双栏模式，且支持整栏收起。
  • 冷会话秒开历史（v1.6.0）：打开已退出的旧会话时，先立即渲染历史消息，再在后台唤醒桌面端运行时；唤醒期间可正常输入并保存草稿，就绪后自动恢复发送。
  • 通知栏快捷审批：开启审批通知提醒后，收到权限请求通知时可直接下拉通知栏点击「批准」或「拒绝」，无需解锁或进入会话。
  • 上下文下钻与配置溯源：用量页点击「组成明细」可查看 11 类上下文占用；消息流中切换过模型或思考档时，消息上方会显示当时的配置快照角标。

三、各品牌手机后台保活建议

可在 App 内「设置 → 后台与通知保障」一键跳转到本机对应设置项。

华为 / 荣耀

设置 → 应用 → 应用启动管理 → ZPocket → 改为「手动管理」，开启自启动、关联启动、后台活动。

vivo / OriginOS

应用管理开启「自启动」，再到「设置 → 电池 → 后台耗电管理」允许 ZPocket 后台运行。

小米 / HyperOS

应用管理开启「自启动」，并将省电策略设为「无限制」。

OPPO / Realme / 一加

应用管理允许自启动与后台运行，并在电池「应用速冻」中移出 ZPocket。

四、工作区文件保存与产物分享

  • 工作区直读保存（不耗模型额度）：点击文件摘要行右侧下载按钮，或直接点按聊天消息里的文件路径，即可预览或保存到手机 SAF 目录（支持进度显示、取消、单文件与本轮产物批量保存）。
  • 流式落盘校验：大文件采用分段写入磁盘 + 逐段 SHA-256 校验，避免低内存手机触发 OOM。
  • 工作流产物收集与分享（顶栏 ⬇）：点击会话顶栏 ⬇ 进入产物页，可一键发送「收集产物」指令让 Agent 发布文件，并对图片、网页、代码或二进制产物进行预览与分享。

五、工作流控制、子代理与后台 Bash

  • 工作流恢复与调参：已中断（取消/失败）的工作流支持一键「恢复」续跑；运行中的工作流支持「调整配置」（切换子代理模型或并发上限），自动停旧起新并保留历史血缘链。
  • 子代理逐条停止：在子代理列表中，可对单个运行中的子代理点击停止，不影响其他任务。
  • 后台 Bash 实时输出：在会话菜单「后台工作」中点开 bash 任务，可查看每秒刷新的实时输出、一键复制或重试。

六、安全、隐私与更新

  • 应用锁与防截屏：支持系统生物识别/锁屏凭证或独立 PIN 码，可配置后台自动锁定时间与防截屏 / 隐藏多任务缩略图。
  • 普通删除 vs 永久删除：普通删除仅移出列表；归档任务中的「永久删除」会彻底清除会话与关联文件，需通过「范围预览 → PIN/锁屏验证 → 结果回执」三段防呆确认。
  • 更新源与完整性校验：设置页支持「自动测速（auto）」「自有服务器（selfhost）」「GitHub Releases（github）」三档更新源，安装前强制校验 SHA-256 与发布签名指纹。

七、常见问题（FAQ）

Q1：为什么「上下文组成明细」或「子代理停止」提示不支持？

这两项功能依赖桌面端 ZCode 3.18+ 协议，请将电脑端 ZCode 升级到 3.18 或最新版本。

Q2：退到后台一段时间后收不到审批通知？

默认策略会在退后台约 90 秒后断开连接以省电。如需实时接收审批推送，请在设置中开启「审批通知后台保活」，并按第三节放行系统后台限制。

Q3：如何确认下载的 APK 安全未篡改？

请仅从 官网下载区 或 GitHub Releases 获取安装包，并核对页面展示的 SHA-256。
