ZPocket 更新日志

记录所有面向用户的功能演进、性能优化与缺陷修复。版本号遵循 SemVer，构建码为 YYYYMMDDNN。

v1.8.2

LATEST 2026-11-23
GitHub Release ↗

高刷新率屏幕适配与流畅度优化版本。

优化 Improved
  • Android 高刷屏适配：在 MainActivity 启动与窗口获焦（含切屏 / 折叠屏展开）时自动选择同物理分辨率下最高刷新率显示模式（90Hz / 120Hz / 144Hz），消除国产高刷机型默认锁 60Hz 导致的滑动发涩感。
  • 流式输出更跟手：流式吐字合帧窗口由 160ms 调优至 64ms（~15.6 FPS），兼顾吐字顺滑度与降频省电。
  • 会话消息重绘隔离：为消息列表项增加 RepaintBoundary，减少长对话滚动与流式输出时的多余重绘。

v1.8.1

2026-11-23
GitHub Release ↗

v1.8.0 质量加固与边界修复版本。

修复 Fixed
  • 通知栏「拒绝并说明」异常隔离：拒绝审批成功后，附言发送失败不再误报「审批未生效」或漏清原审批通知，并将附言结果写入反馈通知正文；消费后自动清理落盘意图键。
  • 台账与快捷指令并发写保护：为 SavedArtifactsStore 与 QuickPromptsStore 增加串行写队列，消除批量保存产物或快速连续删除时的并发覆盖与丢记录风险。
  • 快捷指令草稿保护与空列表修复：「立即发送」改为直接发送而不覆盖或清空输入框中已有草稿；删光全部快捷指令后重新打开保持为空，不再自动复活默认列表。
  • 工作区文件浏览器防竞态与离线提示：引入请求序号避免慢请求覆盖新结果，点按快捷筛选标签先取消防抖；未连接电脑或查询异常时明确展示错误提示。
  • 已保存产物中心体验完善：SAF 另存为在页面销毁前即完成台账记录；隐藏 SAF 条目无效的分享按钮，并为「清空记录」增加二次确认弹窗；补齐 5 条默认快捷指令与新增提示语的英文翻译。

v1.8.0

独立演进 2026-11-23
GitHub Release ↗

ZPocket 独立演进功能与性能优化版本。

新增 Added
  • 工作区轻量文件浏览器：会话菜单新增「工作区文件」入口，支持关键字搜索与常用目录 / 扩展名快捷筛选，点按任意文件即可零额度预览或保存到手机。
  • 通知栏带批注拒绝（RemoteInput）：审批通知新增「拒绝并说明」动作，可在通知栏直接输入拒绝原因，后台受理后自动回传给当前会话；同时修复后台审批动作键名匹配问题。
  • 手机端快捷指令模板：输入栏新增 ⚡ 快捷指令抽屉，内置常用指令并支持一键上屏、立即发送、自定义增删与恢复默认。
  • 本地已保存产物中心：「设置 → 功能 → 已保存产物」集中记录已保存到手机的文件与路径，支持复制路径、移除记录与本地文件复分享。
优化 Improved
  • 流式 Markdown 合帧节流：流式输出期合帧节流降低高速吐字期 CPU 占用与机身发热（非流式交互维持 40ms 即时响应）。
  • 模型选择弹层触控优化：ModelSheet 列表行最小高度提升至 48dp，满足 Material 触控标准。

v1.7.0

2026-11-23
GitHub Release ↗

上游同步版本（合入上游 zcode-pocket v1.0.9，已验证兼容 ZCode 桌面端 3.19.1）。

新增 Added
  • PDF 产物应用内预览：支持原生渲染翻页、缩放与分享，损坏或受保护文件自动降级导出（新增 PdfRendererPlugin）。
  • 会话内搜索增强：支持多词 AND 搜索全词高亮、正则开关（含回溯预检）、「含思考」开关与历史边界继续往前搜。
  • 扫码实时预览按机型分流：非问题机型恢复实时取景，支持胶囊按钮切换与偏好记忆。
  • 收集产物完成直达条：输入区上方展示已收集产物数量，一键进入详情页；收集产物自动激活工作流。
  • 平板 / 折叠屏横屏解锁：短边 ≥600dp 设备跟随系统旋转与分屏，窄屏手机保持竖屏锁定。
  • 任务完成横幅通知开关：支持高优渠道顶部弹窗提醒（默认关闭）。
  • 子代理模型按提供方分组：组头显示套餐徽标并支持折叠。

v1.6.0

2026-11-21
GitHub Release ↗

上游同步与 ZCode 3.19 兼容性版本（合入上游 zcode-pocket v1.0.8）。

新增 Added
  • 冷会话秒开历史（需桌面端 3.18+）：打开已退出的旧会话先立即渲染历史消息，再在后台唤醒运行时；唤醒期间可输入存草稿，失败提供原因与一键重试。
  • 后台 Bash 实时输出查看：后台工作中的 bash 任务支持点开查看每秒刷新的实时输出、一键复制与重试；失败任务在列表行显示错误摘要（需桌面端 3.19+）。
  • 工作流运行控制（需桌面端 3.18+）：中断的工作流支持一键恢复续跑；运行中支持调整子代理模型与并发上限，自动停旧起新并保留历史可回看。
  • 官方福利投递提醒：任务主页展示官方免费额度活动卡片，支持收起 / 展开与误关撤销。
修复 Fixed
  • 修复带按钮的提示条（如任务归档撤销、通知定位、福利卡关闭）常驻不消失的问题，统一改为约 4 秒自动消失；优化宽屏福利卡操作按钮对齐。
