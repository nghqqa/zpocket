# T1 静态性能深审报告（v1.2.2 代码基线，2026-11-13）

> 范围：渲染管线 / 内存形态 / 网络与传输 三域代码级审查。方法：静态代码取证（无真机数据——真机 profiling 属 T2，操作单见文末）。
> 结论先行：**上游底盘成熟，无需大动**；确认 1 个自研热点（下载全内存缓冲）与 2 个低风险增长点；全部附改造方案，按需启用。

## 一、渲染管线

| 项 | 结论 | 证据 |
| --- | --- | --- |
| 会话轮次列表 | ✅ 懒渲染 | `ListView.builder`（conversation_page.dart:3724），滚出视口即回收 |
| Markdown 重解析 | ✅ 有防护 | 未变轮次走 identical 短路跳过整棵子树 rebuild（conversation_message_cells.dart:190/384） |
| 流式输出 | ✅ 官方策略继承 | streaming 期间关闭语法高亮（markdown_view.dart），减少每 chunk 解析成本；chunk 级重建仍存在，为官方接受的实时性折衷 |
| 流程页面 | ✅ | 任务主页 ListView.builder、设置页分区渲染 |
| 风险点：滚动到底悬浮球 | ⚠️ 低 | 悬浮球与末行下载钮的位置冲突已在 v1.2.2 以 72dp 底部让位缓解；悬浮球可拖拽，极端摆放仍可能压内容（用户可控，不修） |

**判定：渲染管线无需优化。** 若 T2 真机发现流式输出帧率毛刺，首查点是 MarkdownBody 每 chunk 全文重解析的节流（加 150–300ms 合帧），但当前无证据支持动它。

## 二、内存形态

| 项 | 结论 | 说明 |
| --- | --- | --- |
| 通知台账 | ✅ 封顶 500 条 | notify_store.dart:_maxInteractions |
| 本地缓存快照 | ✅ 行数截断 | local_cache.dart capRows |
| 会话页 ViewStore 映射（fileCardOpen/fileCardItems） | ⚠️ 无清理但量级小 | 按 rowId 累积（每轮一个 bool + 展开时一份文件清单），会话级生命周期；数千轮会话约数百 KB，可忽略 |
| 附件预览 | ✅ 有界 | 图片走 Image.memory（来源 readMediaPreview ≤8MB / 附件 ≤20MB） |
| **工作区文件下载** | ⚠️ **全内存累积（本次唯一确认热点）** | workspaceReadFileBytes 用 BytesBuilder 攒完整字节再返回（conversation.dart:1622-1645）——上限 100MB=下载期间内存等额峰值；低端机（3-4GB RAM）在同时渲染会话时可能触发内存压力 |

**热点改造方案（T3 备选，未实施）——下载流式落盘：**

1. `workspaceReadFileBytesToTemp(path)`：分段 `readFileRange` 直接 append 到 `path_provider` 临时文件（`IOSink.addStream` / 逐段 `writeFrom`），返回 `{file, sha256 逐段累加}`，校验通过后由保存流程直接move/copy到 SAF 目标——内存峰值从 O(文件) 降到 O(1MiB 分段)。
2. 受益场景：几十 MB 的 APK/PDF/视频产物 + 低端机；普通文档（<5MB）收益为零，可不改。
3. 改动面：transport 1 处 + file_save 1 处 + 测试 1 个，约半天。
4. 不做的代价：大文件+低端机的 OOM 小概率事件；做错的风险：临时文件清理遗漏——实现时用 `finally` 删除。

**触发条件建议**：T2 真机若出现下载期间内存压力/OOM，或用户反馈大文件下载失败率异常，再启动。

## 三、网络与传输

| 项 | 结论 |
| --- | --- |
| 心跳 | 4–6s 协议要求（上游设计，不可调） |
| 断线重连 | 指数退避 + 重连风暴防护（被踢 5 分钟冷静期）已有 |
| 分段下载 | 1MiB 分段 + Range 续传（416 复用判定已有测试）+ 1s 打散超时 |
| 更新源测速 | 双通道 RTT 探测 2s 超时，不阻塞主流程 |
| 弱网取消 | 批量可取消（v1.2.2 已实现）；单文件可取消（v1.2.2 已实现） |

**判定：传输层已覆盖弱网主路径，无需新增。** 未覆盖的极限用例（供 T2 参考）：16KB/s 限速下载 50MB 文件的中途取消+重试；飞行模式瞬断的心跳重连窗口。
