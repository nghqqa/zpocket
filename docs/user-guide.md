# ZPocket 用户手册（v1.7.0）

> ZPocket 是 [ZCode](https://github.com/zai-org/ZCode) 桌面编程智能体的安卓伴侣客户端（基于 `zcode-pocket` Apache-2.0 分支演进）。本手册面向日常手机端使用，涵盖配对连接、通知快捷审批、文件保存、工作流控制与隐私安全。

---

## 一、安装与首次配对

### 1. 环境要求
- **手机端**：Android 7.0 及以上（支持主流 `arm64-v8a`、`armeabi-v7a` 与 `x86_64` 架构）。
- **桌面端**：电脑已安装并登录 **ZCode 桌面端**（部分新特性如上下文下钻、子代理逐条停止、冷会话秒开需 **3.18+**；后台 Bash 失败摘要需 **3.19+**）。

### 2. 下载与安装
- **官网下载**：前往 [zpocket.nghqqa.cn](https://zpocket.nghqqa.cn/) 选择对应架构的 APK（绝大多数手机选 `arm64-v8a`）。
- **GitHub Releases**：前往 [GitHub Releases](https://github.com/nghqqa/zpocket/releases) 下载对应版本与 `SHA256SUMS.txt` 校验。

### 3. 连接桌面端
1. 打开 ZPocket，使用与桌面端 ZCode 相同的账号登录，或使用**扫码配对**连接桌面端。
2. 若有多台电脑，每台电脑在 App 内独立隔离管理，可在顶部或设备列表显式切换目标电脑。
3. 支持官方云端中继（`wss://zcode.z.ai`）与局域网直连回退。

## 二、日常使用核心功能

### 1. 任务主页与冷会话秒开
- **任务列表**：按时间与项目分组展示，支持项目排序、置顶与归档；宽屏设备（平板 / 折叠屏展开态，逻辑宽度 ≥600dp）自动启用「左栏任务 + 右栏会话」双栏模式，支持整栏收起。
- **冷会话秒开历史**（v1.6.0）：点开已退出的旧会话时，App 会**先立即渲染历史消息**，再在后台唤醒桌面端运行时。唤醒期间你可以先输入内容并保存草稿，就绪后恢复发送；若唤醒失败可查看原因并一键重试。

### 2. 权限审批与通知栏快捷应答
- **富文本预览**：Agent 请求执行命令或修改文件时，审批卡片会展示完整命令、参数与工作区上下文。
- **通知栏快捷审批**：在启用后台/审批通知提醒后，收到审批推送时可直接下拉通知栏，点击 **「批准」** 或 **「拒绝」** 完成应答，无需解锁进入会话。

> **不同品牌手机后台保活建议**（可在 App 内「设置 → 后台与通知保障」查看本机专属引导）：
> - **华为 / 荣耀**：设置 → 应用 → 应用启动管理 → ZPocket → 改为「手动管理」，开启自启动、关联启动、后台活动。
> - **vivo / OriginOS**：应用管理开启「自启动」，再到 **设置 → 电池 → 后台耗电管理** 允许 ZPocket 后台运行。
> - **小米 / MIUI / HyperOS**：应用管理开启「自启动」，并将省电策略设为「无限制」。
> - **OPPO / Realme / 一加**：应用管理允许自启动与后台运行，并在电池「应用速冻」中移出 ZPocket。

### 3. 工作区文件保存与产物分享
ZPocket 提供两种互补的取文件方式：
1. **工作区直读保存到手机**（不消耗模型额度）：
   - 点击文件摘要行右侧的下载按钮，或**直接点按对话消息里的文件路径**，选择「预览」或「保存到手机」（支持进度显示、中途取消、单文件与本轮产物一键批量保存至手机 SAF 目录）。
   - 大文件采用分段流式落盘 + SHA-256 校验，避免手机内存溢出。
2. **工作流产物收集与分享**（顶栏 ⬇ 入口）：
   - 点击会话顶栏 `⬇` 图标进入产物页，可一键发送「收集产物」指令让 Agent 发布产物，或对工作流产出的图片、网页、文本及二进制文件进行预览、分享与保存。

### 4. 工作流控制、子代理与后台 Bash
- **工作流运行控制**（顶栏入口，带运行中计数）：
  - 已中断（取消/失败）的工作流支持一键 **「恢复」** 续跑。
  - 运行中的工作流支持 **「调整配置」**（切换子代理模型或并发上限），系统会自动停旧起新并保留历史血缘链可回看。
- **子代理逐条停止**：在会话子代理列表中，可对单个运行中的子代理单独点击停止，不影响其他任务。
- **后台 Bash 实时输出**：在会话菜单「后台工作」中点开任意 bash 任务，可查看每秒刷新的实时输出、一键复制尾部日志或重试。

### 5. 用量与上下文下钻
- 在用量页可查看额度消耗与热力图，点击 **「组成明细」** 可下钻查看 11 类上下文占用（系统提示词、工具定义、技能、消息等）及各条目 token 占比。
- 消息流中若切换了模型、思考档或协作模式，会在对应消息上方显示当时的配置溯源角标。

## 三、安全、隐私与更新

### 1. 应用锁与隐私保护
- **应用锁**：可在「设置 → 安全」开启，支持系统生物识别/锁屏凭证或独立 PIN 码，支持配置后台自动锁定超时与**防截屏 / 隐藏多任务缩略图**。
- **本地缓存清理**：「设置 → 关于 → 清除本地缓存」可删除本机任务/会话快照与通知台账（明文 JSON 缓存，已禁用系统云备份），不会清除草稿、排队消息与账号凭据。

### 2. 归档删除 vs 永久删除
- **普通删除**：仅将任务移出当前列表，桌面端数据仍保留。
- **永久删除**：在归档列表中可发起彻底删除（含子会话与工作区文件，不可恢复），需经过「范围预览 → 应用锁 PIN / 系统锁屏验证 → 结果回执」三段防呆确认。

### 3. 应用内更新与更新源切换
- App 默认开启应用内更新检查，支持 **自动测速择优（auto）**、**自有服务器（selfhost，国内直连快）** 与 **GitHub Releases（github）** 三档切换。
- 所有更新包在安装前均强制校验 `SHA-256` 摘要与发布签名指纹（`f9ffa6fa…`），确保安装包未被篡改。

## 四、常见问题（FAQ）

1. **为什么点击「上下文组成明细」或「子代理停止」提示不支持？**
   - 这两项依赖桌面端 ZCode **3.18+** 协议，请将电脑端 ZCode 升级到 3.18 或最新版本。
2. **手机退到后台一段时间后收不到审批推送？**
   - 默认策略在退后台约 90 秒后会断开长连接以省电；如需实时接收审批推送，请在设置中开启「审批通知后台保活」并按前文引导放行系统的自启动与电池限制。
3. **如何确认自己下载的 APK 是正版？**
   - 请仅从 [zpocket.nghqqa.cn](https://zpocket.nghqqa.cn/) 或 [github.com/nghqqa/zpocket/releases](https://github.com/nghqqa/zpocket/releases) 下载，并核对页面给出的 `SHA-256` 校验和。
